Datenschutzerklaerung Buero Home

Buero Home wird ausschliesslich vom Inhaber fuer das eigene Google-Konto genutzt.

Die Anwendung liest per Google-API (Gmail) die Nachrichten des Inhabers und speichert sie auf dessen eigenem Server im Heimnetz. Es werden keine Daten an Dritte weitergegeben, verkauft oder fuer Werbung genutzt.

Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschraenkten Nutzung (Limited Use).

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
